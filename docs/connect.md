# Connect your store to the chat

Short version. The full guide is in the help pages:
[PrestaShop](https://tellmyshop.com/docs/getting-started/connect-claude?utm_source=github&utm_medium=referral&utm_campaign=linki-zewnetrzne) · [WordPress](https://tellmyshop.com/docs/wordpress/start?utm_source=github&utm_medium=referral&utm_campaign=linki-zewnetrzne)

## 1. Switch on the connector and copy the address

After installing the module or plugin, open the TellMyShop panel, click **Switch on the connector** and copy the **shop address for the chat**. The address is not secret: it gives no access until you approve it in your store.

## 2a. Claude

Settings → Connectors → **Add** → **Add custom connector** → give it a name and paste the address → **Add**, then **Connect**. Any Claude account works, including the free one. A connector added on claude.ai also works in the desktop and phone apps.

## 2b. ChatGPT

**Plugins** → **Add** → **Add custom MCP server** → paste the address under Server URL, choose **OAuth** → **Create**. A free ChatGPT account works too.

## 3. Allow in the store window

The chat opens a window of your store. Signed in as the store owner, choose **Read and changes with your approval** or **Read only**, and click **Allow**. Not signed in on this device? The window shows a code that you enter in the panel. You can disconnect any chat later on the Connected chats card.

## 4. First conversation

Ask for a store review, for example: "Check my store and list what to fix first." The panel has ready-made tasks to start from.

## Something does not work?

See [When something doesn't work](https://tellmyshop.com/docs/getting-started/when-it-doesnt-work?utm_source=github&utm_medium=referral&utm_campaign=linki-zewnetrzne). The panel has a connection test that names the most common causes, for example a hosting firewall blocking the address.
