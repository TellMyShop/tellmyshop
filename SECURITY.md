# Security

If you find a security problem in TellMyShop, please do not open a public issue. Write to **support@tellmyshop.com** with:

- the platform and version (PrestaShop or WordPress, TellMyShop version),
- what happens and how to reproduce it.

Never send your licence key, passwords or customer data. We reply as soon as we can and tell you when a fix is released.
